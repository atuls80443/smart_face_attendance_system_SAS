# AI-Based Face Recognition Attendance System

## Overview
AI-powered Face Recognition Attendance System 
The system captures live video from a phone camera, detects student's face, recognize the student using AI-based face recognition and automatically marks attendance.

## Objectives
for demo or prototype demostration
- Capture live video from a phone camera
- Detect faces in real time 
- Register student faces
- Recognize registered students
- Automatically mark attendance 
- Prevent duplicate attendance 
- Display attendance status on screen
